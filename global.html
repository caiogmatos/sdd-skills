G·02
Install Skills
~/.claude/skills/ — one subfolder per skill, file must be named SKILL.md
+
folder name = slash command name file must be named exactly SKILL.md no restart needed — picked up live
01
Windows path — C:\Users\<Name>\.claude\skills\
02
WSL path — ~/.claude/skills/ (prefer this over /mnt/c/)
03
One folder per skill — e.g. skills/sdd-startup/SKILL.md
04
Rename downloads — the download button saves sdd-[name]-SKILL.md; move each into its folder as SKILL.md (or run the command below)
05
No restart needed — changes are picked up live. Only if ~/.claude/skills/ didn't exist when the session started, run /reload-skills
06
Verify — type / and your skill names should autocomplete
# Windows (PowerShell) — after downloading all six foreach ($n in 'startup','bootstrap','checkup','feature','implement','validate') { $t = "$HOME\.claude\skills\sdd-$n" New-Item -ItemType Directory -Force $t | Out-Null Move-Item "$HOME\Downloads\sdd-$n-SKILL.md" "$t\SKILL.md" -Force } # macOS / Linux (in WSL use /mnt/c/Users/<Name>/Downloads) for n in startup bootstrap checkup feature implement validate; do mkdir -p ~/.claude/skills/sdd-$n mv ~/Downloads/sdd-$n-SKILL.md ~/.claude/skills/sdd-$n/SKILL.md done
~/.claude/skills/ ├── sdd-startup/ │ └── SKILL.md ├── sdd-bootstrap/ │ └── SKILL.md ├── sdd-checkup/ │ └── SKILL.md ├── sdd-feature/ │ └── SKILL.md ├── sdd-implement/ │ └── SKILL.md └── sdd-validate/ └── SKILL.md
Common mistake: placing SKILL.md directly in skills/ root, or naming the file sdd-feature.md instead of SKILL.md. Neither will be detected.

Model Selection
Sonnet for everyday work · opusplan for SDD sessions · switch mid-session with /model
+
✓
Sonnet 4.6 — default for most accounts. Best balance of speed, quality, and cost for everyday coding tasks.
✓
opusplan — smart hybrid alias. Uses Opus for plan/design phases, drops to Sonnet for code generation automatically. Best for SDD sessions.
↑
Opus 4.8 — escalate when complexity demands it: large codebase refactors, high-stakes architecture decisions, deeply chained reasoning.
✗
Do not declare model in CLAUDE.md — set it per session or use --model flag at launch.
# Best for SDD sessions claude --model opusplan # Everyday default claude --model sonnet # Switch mid-session /model # opens picker /model sonnet # switch immediately # Context is preserved on switch
opusplan for SDD: Spec and design phases get Opus reasoning. Implementation tasks get Sonnet speed. Matches exactly how sessions are structured.
